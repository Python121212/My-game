# My-game

This repository includes [GameNative](https://github.com/utkarshdalal/GameNative) as a Git submodule.

Clone this repository and initialize GameNative and its own submodules with:

```sh
git clone --recurse-submodules https://github.com/Python121212/My-game.git
```

For an existing clone, run:

```sh
git submodule update --init --recursive
```

See `GameNative/README.md` for project information and build instructions. GameNative is licensed under GPL-3.0; see `GameNative/LICENSE` for the full license.
